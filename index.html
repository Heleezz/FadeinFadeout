Conceitos Fundamentais

      
opacity vs visibility vs display

      

        Embora todas possam "esconder" um elemento, elas se comportam de formas radicalmente diferentes no pipeline de renderização do navegador.
      


      

        
        

          
opacity: 0

          
Torna o elemento totalmente transparente, mas ele continua ocupando espaço e respondendo a eventos.

          
    
            
  • ✓ Mantém espaço no layout
    • 
            
  • ! Responde a cliques (use pointer-events: none)
    • 
            
  • ✓ Animável suavemente (0 → 1)
    • 
            
  • ✓ Processado na GPU (composite only)
    • 
          

        


        
        

          
visibility: hidden

          
Esconde o elemento visualmente sem removê-lo do fluxo do documento.

          
    
            
  • ✓ Mantém espaço no layout
    • 
            
  • ✕ Não responde a eventos
    • 
            
  • ✕ Transição discreta (sem interpolação)
    • 
            
  • ✓ Herdado por elementos filhos
    • 
          

        


        
        

          
display: none

          
Remove completamente o elemento do fluxo do DOM e da árvore de renderização.

          
    
            
  • ✕ Não ocupa espaço no layout
    • 
            
  • ✕ Não responde a eventos
    • 
            
  • ✕ Não pode ser animado
    • 
            
  • ! Força reflow ao ser alternado
    •
